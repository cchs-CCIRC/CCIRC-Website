LEARNING PATH

C++ 競技程式學習路線

我們正式教學只以 C++ 為主。不是把知識背完，而是理解概念後一起練題、討論與修正——從完全零基礎到 APCS 實作高分的循序漸進闖關指南。

01
新手入門

Stage 1：C++ 基礎語法與邏輯

扎實打好程式根基，學會如何用程式碼解決基本的數學與邏輯問題。

  • 基本的輸入輸出（cin / cout）
  • 變數型態與運算子（int, double, char, bool）
  • 條件判斷（if / else / switch）
  • 迴圈控制（for / while）
  • 一維與二維陣列（Array）與函式（Function）
🎯 目標：APCS 觀念題 2～3 級分
02
進階應用

Stage 2：資料結構入門 & STL 容器

學會 C++ 內建的強大工具箱，讓資料處理與搜尋變得簡單又有效率。

  • 字串處理（string）
  • 動態陣列 vector
  • 堆疊與佇列（stack / std::queue）
  • STL（map / set）
  • 結構（struct）與自訂排序規則
🎯 目標：APCS 實作題第 1～2 題過關
03
演算法核心

Stage 3：經典基礎演算法

掌握資訊競賽必備的思維方式，學習如何優化程式碼的時間複雜度。

  • 時間與空間複雜度概念（O(N)）
  • 二分搜尋法（Binary Search）
  • 遞迴思考（Recursion）與費氏數列
  • 貪婪法（Greedy Algorithm）
  • 雙指標（Two Pointers）與滑動視窗（Sliding Window）
🎯 目標：APCS 觀念題 4 級分／實作第 3 題
04
高階實戰

Stage 4：APCS 衝刺與進階主題

挑戰高階演算法題型，建立圖論與動態規劃的完整觀念。

  • 深度優先搜尋（DFS）與廣度優先搜尋（BFS）
  • 分治法（Divide and Conquer）
  • 動態規劃基礎（Dynamic Programming, DP）
  • 歷屆 APCS 實作題真題解題與刷題策略
🎯 目標：APCS 實作題 4～5 級分衝刺
